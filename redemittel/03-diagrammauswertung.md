# 3. Diagrammauswertung

> **¿Qué tengo que hacer?** (1) Dar los **Rahmendaten**, (2) describir y comparar los **valores centrales**, (3) **interpretar** (no solo describir) y (4) pasar a la Stellungnahme.

## Was musst du tun?
- der Grafik die wesentlichen Informationen entnehmen und auswerten
- zur begründeten Stellungnahme überleiten

## Schritt 1: Rahmendaten benennen
Checklist: ☐ Thema/Fragestellung ☐ ggf. Gruppe der Befragten ☐ Quelle ☐ Erscheinungsdatum ☐ Darstellungsform ☐ ggf. Kategorien ☐ ggf. Einheiten

### das Thema / die Fragestellung (und ggf. die Befragten) benennen
- Das Schaubild / Die Grafik / Die Statistik gibt Auskunft über … / informiert über …
- Das Schaubild / Die Grafik / Die Statistik zeigt, …
- In dem (vorliegenden) Schaubild / der Grafik / der Statistik ist … zu sehen.
- Aus der Darstellung ergibt sich …
- Das Schaubild / Die Grafik / Die Statistik zeigt die Veränderungen / die Entwicklung / die Verteilung von …
- Dem Schaubild / Der Grafik / Der Statistik kann man entnehmen / ist zu entnehmen, wer/wann/wo/wie lange/wie viele …
- Das Schaubild / Die Grafik / Die Statistik veranschaulicht die Meinung der … (Befragte) zu der Fragestellung, …
- Das Schaubild / Die Grafik / Die Statistik zeigt die Ergebnisse einer Umfrage unter … (Befragte) zu folgender Frage: …

### Quelle und Erscheinungsdatum angeben
- Die Daten/Informationen stammen aus … vom …
- Sie wurden von … am … veröffentlicht.
- Die Grafik ist der Studie … entnommen.
- Die Zahlen legte … (das Statistische Bundesamt, das Institut für …) am … / im Jahr … vor.

### die Darstellungsform angeben
- Das Balkendiagramm / Säulendiagramm veranschaulicht …
- Wie das Kreisdiagramm zeigt, …
- Als Darstellungsform wurde … gewählt.

## Schritt 2: zentrale Werte beschreiben und vergleichen

### Rangordnung
- An erster Stelle steht/liegt … · An der Spitze liegen … · Spitzenreiter ist … / Die Spitzenstellung nimmt … ein.
- An zweiter/dritter/… Stelle folgt …
- Im Mittelfeld finden wir … · In der Mitte liegen/befinden sich … · Auf den mittleren Plätzen sind …
- An letzter Stelle steht/liegt … · Das Schlusslicht bildet … · Auf den hinteren/unteren Plätzen der Statistik liegen/finden wir …

### Verlauf der Daten
- ⬇️ Die Zahl der … hat (um x Prozent) abgenommen / ist gefallen / ist gesunken / ist zurückgegangen / hat sich reduziert / hat sich verringert / hat sich verkleinert.
- ⬇️ … hat (von x Prozent auf y Prozent) abgenommen / ist rückläufig / ist gefallen.
- ➡️ … ist gegenüber (Zeitpunkt) gleich / konstant / unverändert geblieben.
- ➡️ … hat sich nicht verändert / stagniert / ist gleich geblieben.
- ⬆️ … hat sich erhöht / vergrößert.
- ⬆️ … hat zugenommen / ist (an)gestiegen.

### Auffälligkeiten
- Was besonders auffällt, ist …
- Was ins Auge springt/fällt, ist …
- Bemerkenswert / Auffällig ist …
- Es fällt auf, dass …
- Überraschend ist, dass …

### Prozentanteile ⚠️ (¡ojo al verbo!)
- x Prozent (+ Genitiv) haben/sind … → **Verb im Plural!** *x % aller Befragten **hoffen**, …*
- Auf x % aller Befragten entfallen y % aller genannten Straftaten.
- Der Anteil / Der Prozentsatz (+ Genitiv oder an + Dativ) liegt bei / beträgt x Prozent → **Verb im Singular!**

### Vergleiche
- Die Bedeutung von … nimmt im Gegensatz zu … immer weiter zu.
- Im Gegensatz zu … bleibt … konstant.
- Wenn man die Ergebnisse miteinander vergleicht, fällt auf, …
- Im Vergleich zu den befragten (Studierenden/Arbeitssuchenden, …) …

## Schritt 3: die Grafik auswerten
- Daten interpretieren bzw. die **Hauptaussage(n)** formulieren
- optional: Erklärungsansatz (Warum fällt die Grafik so aus?) und/oder **Bezug zum Text**

### interpretieren / Hauptaussage formulieren
- Bezüglich des erfassten Zeitraums kann gesagt werden, dass …
- Es ist festzustellen, dass … in den letzten Jahren tendenziell steigt/sinkt.
- Das Schaubild zeigt deutlich den kontinuierlichen Rückgang/Anstieg des/der …
- Wir können also feststellen, dass …
- Dem Schaubild ist also zu entnehmen, dass …
- Es lässt sich zusammenfassend festhalten, dass …

### Erklärungsansatz / Bezug zum Text
- Die Daten sind (nicht) überraschend, weil …
- Abschließend kann man sagen, dass die vorliegenden Daten die Aussagen des Textes stützen, da …

## Gut zu wissen: Diagrammarten
| Diagramm | Darstellung | Funktion |
|---|---|---|
| **Säulendiagramm** | senkrechte Säulen | Größen vergleichen, Tendenzen feststellen, Verlauf verfolgen |
| **Balkendiagramm** | waagerechte Balken | Zustand oder Entwicklung beschreiben |
| **Kreisdiagramm** | Kreissegmente, Gesamtmenge = 100 % | Größen vergleichen, Zustand beschreiben |
| **Linien-/Kurvendiagramm** | Linien/Kurven | Entwicklung/Veränderung im zeitlichen Verlauf |

Manchmal gibt es **zwei Diagramme** – dann beide auswerten!
