# 4a. Begründete Stellungnahme – dialektische Erörterung (Pro & Contra)

> **¿Qué tengo que hacer?** Presentar argumentos **a favor y en contra**, y dejar **clara mi opinión**. Es la parte más larga e importante del texto.

## Was musst du tun?
- deine eigene Meinung zur vorgegebenen Fragestellung verdeutlichen
- deine eigene Meinung durch eine differenzierte Argumentation, die Pro- und Contra-Argumente ausarbeitet, stützen
- zum Schluss überleiten

## Gut zu wissen: Wie sieht ein ausgearbeitetes Argument aus?
Un argumento **no** es solo tesis + razón. Debe tener:
1. **These** (afirmación)
2. **Begründung** (por qué)
3. **Beweis/Beleg** y/o **Veranschaulichung** (Beispiel, Erfahrung)
4. y/o **Schlussfolgerung** (conclusión del argumento)

➡️ Zeitform: **Präsens**.

## Aufbau – zwei Wege
**Weg 1 (en bloques):** alle Pro-Argumente (oder alle Contra) → alle Contra-Argumente (oder alle Pro) → eigene Meinung
**Weg 2 (alternando):** Pro 1 → Contra 1 → Pro 2 → Contra 2 … → eigene Meinung

💡 Consejo: pon **al final** el lado que coincide con tu opinión; así la transición a tu opinión es natural.

La eigene Meinung puede ir:
- **separat** con una razón propia (nuevos argumentos o referencia a los ya dados), **o**
- **als Konsequenz** de la Erörterung (refiriéndote a tus argumentos y/o rebatiendo los contrarios).
Para la nota **da igual** cuál elijas.

## Redemittel

### Pro-Argumente benennen
- Befürworter/innen einer solchen Lösung argumentieren, dass …
- Befürworter/innen einer solchen Lösung vertreten die Ansicht, dass …
- Dafür spricht, dass …
- Was dafür spricht, ist …
- Das Hauptargument für … bezieht sich auf …

### Contra-Argumente benennen
- Dagegen spricht, dass …
- Einer der wichtigsten Gründe, der gegen … angeführt wird, ist …
- Der wichtigste Einwand bezieht sich auf …
- Gegner/innen einer solchen Lösung argumentieren / vertreten die Ansicht, dass …
- Was dagegen spricht, ist …
- Ein weiteres Argument gegen … ist …

### Vor- und/oder Nachteile benennen
- Ein/Der Vorteil bei … ist …
- Ein/Der Nachteil von … ist, dass …
- Ein weiterer Nachteil/Vorteil ist …
- Positiv ist auch zu bewerten, dass …
- Nützlich ist zudem …
- Negativ ist zudem …
- Eine ungünstige/nachteilige Folge ist, dass …
- Was für/gegen … spricht, ist …
- Vorteilhaft/Nachteilig ist, dass …
- … hat den Vorteil/Nachteil, dass …
- … ist besonders geeignet für/bei …

### vergleichen und abwägen
- An … ist positiv/negativ, dass …
- Auf der einen Seite … Auf der anderen Seite …
- Dem gegenüber steht allerdings …
- Einerseits …, andererseits …
- Die einen sind dafür, dass … Die anderen lehnen … ab, dass …
- Gegenüber … hat … den Vorteil, dass …
- … hingegen argumentiert, dass …
- Im Gegensatz / Im Vergleich / Im Unterschied zu …
- Während die einen meinen, dass …, sind die anderen der Ansicht, dass …

### zu einem gleichwertigen Argument überleiten
- Zunächst einmal … / An erster Stelle wäre zu nennen …
- Dann aber auch … / Ferner … / Ein weiteres …
- Nicht weniger wichtig ist …
- Darüber hinaus bleibt auch zu bedenken …
- Ebenfalls … / Weiterhin … / Ebenso … / Außerdem … / Hinzu kommt …
- Eng damit verknüpft ist … / Ähnlich steht es um … / Nicht anders ist es mit …
- Zu guter Letzt … / Schließlich sei daran erinnert, dass …
- Außerdem ist zu bedenken, dass …
- Darüber hinaus wurde die Erfahrung gemacht, dass …

### zu einem gegensätzlichen Argument überleiten
- Nicht nur …, man muss auch …
- Einerseits …, andererseits …
- Dem gegenüber ist aber auch zu bedenken …
- Aber auch … / Dem steht allerdings entgegen … / Es darf jedoch auch nicht übersehen werden, dass …
- Trotz all dieser Gründe darf nicht übersehen werden, dass …
- Wie aber verhält es sich dagegen mit …
- Zwar …, aber …
- Im Gegensatz dazu steht … / Anders verhält es sich bei … / Ganz anders stellt sich … dar.

### zu einem sich steigernden Argument überleiten
- Schwieriger wird es schon mit … / Gewichtiger ist da schon …
- Eine erneute Steigerung der Schwierigkeiten ergibt sich … / Noch bedeutsamer aber ist …
- Besonders wichtig aber erscheint mir …

### von Pro zu Contra (Vorteile → Nachteile) wechseln
- Nach den Vorteilen komme ich nun zu den Nachteilen.
- Nachdem ich die Vorteile betrachtet habe, muss ich aber auch auf die Nachteile hinweisen.
- Nicht nur die Vorteile, auch die Nachteile müssen betrachtet werden.

### Beispiele, Belege, Erfahrungen angeben
- Zu diesem Argument kann folgendes Beispiel angeführt werden: …
- Dies lässt sich anhand des folgenden Beispiels verdeutlichen: …
- Ein Beispiel dafür ist …
- Das lässt sich mit folgenden Zahlen belegen: …
- Dies habe ich zum Beispiel in … erlebt, als …
- Das zeigt sich anhand dieser Fakten: …

### zur eigenen Meinung überleiten
- Nachdem erörtert wurde, wie/welche/was …, soll nun meine Meinung zu diesem Thema dargelegt werden.
- Nach der Erörterung des … (Thema) komme ich nun … / folgt nun …
- Wenn man mich persönlich fragen würde, …
- Gerade dieses Argument ist auch für meine Haltung zu diesem Thema wichtig. Auch ich bin der Meinung, dass …

## Redemittel zur schlüssigen eigenen Meinung

### die eigene Meinung benennen
- Meiner Meinung nach …
- Ich bin der Auffassung, dass … / Ich bin der Meinung, dass …
- In Bezug auf … vertrete ich die Meinung/die Position, dass …
- Ich bin der (festen) Überzeugung, dass … / Ich bin überzeugt davon, dass …
- Ich begrüße es, wenn … / Ich würde es begrüßen, wenn …
- Ich muss zustimmen, dass …
- Mit Sicherheit kann ich behaupten, dass …

### die eigene Meinung durch Distanzierung benennen
- Ich lehne … ab.
- Ich verurteile …
- Es steht für mich fest, dass …
- Alles in allem glaube ich, dass …
- Es erscheint mir problematisch, dass …
- Es entspricht nicht meinen Erfahrungen, …
- Ich kann die Meinung des Verfassers (nicht) teilen, weil …

### die eigene Meinung begründen
- Man kann einige wichtige Argumente dafür/dagegen anführen: … Eine Ursache sehe ich in …
- Folgende Gründe möchte ich dafür/dagegen anführen/nennen/geltend machen: …
- Aus diesem Grund …
- Diese Ansicht/Meinung/Behauptung wird durch … belegt / dadurch belegt, dass …

### auf Argumente verweisen und diese ggf. entkräften
- Wie ich oben schon erklärt/ausgeführt habe, …
- Schon eingangs wurde dargelegt, dass …
- Wie bereits oben dargelegt/beschrieben, …
- … Dies sehe ich anders, weil …
- … Das ist für mich kein überzeugendes Argument, da …
