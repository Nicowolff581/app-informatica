# 2. Textwiedergabe

> **¿Qué tengo que hacer?** Resumir con **mis propias palabras** las ideas principales del Sachtext, **párrafo por párrafo**, y pasar al diagrama.
> ⚠️ Cada párrafo tiene al menos una idea importante. **Si me salto un párrafo, ya no puedo tener la puntuación máxima en "Vollständigkeit".**

## Was musst du tun?
- die wichtigsten Aussagen im vorgegebenen Sachtext erkennen und diese mit eigenen Worten wiedergeben
- zur Diagrammauswertung überleiten

## Schritt 1: Basissatz
Debe contener: **Titel · Verfasser/in · Thema/Problematik · Quelle · Erscheinungsdatum**

### mit der Textwiedergabe beginnen
- In dem Text/Artikel „…“ von … (Verfasser/in) in/aus … (Quelle) vom … (Erscheinungsdatum) geht es um Folgendes: …
- Der Text/Artikel (mit dem Titel) „…“ von … (Verfasser/in), publiziert/veröffentlicht am … (Erscheinungsdatum) in … (Quelle), thematisiert …

### das Hauptproblem nach dem Basissatz benennen
- Dieses Thema steht auch im Mittelpunkt des Artikels/Textes von … (Verfasser/in).
- Mit diesem Thema befasst sich auch … (Verfasser/in) in seinem/ihrem (gleichnamigen) Beitrag (mit dem Titel …) in/aus … (Quelle) vom … (Erscheinungsdatum).

## Schritt 2: Hauptaussagen je Absatz wiedergeben
- die zentrale(n) Aussage(n) **jedes Absatzes** in **ein oder zwei Sätzen** mit eigenen Worten wiedergeben
- Synonyme und Umschreibungen für die Wörter im Text finden

## Schritt 3: die Sätze miteinander verbinden
- Im Text steht, …
- Die/Der Verfasser/in berichtet (über) …
- Ein wichtiger/zentraler Punkt des Textes ist …
- Es wird außerdem dargestellt, wie … / dass …
- Es wird zudem beschrieben, dass …
- Zum Schluss weist der Text darauf hin, dass …

## Gut zu wissen: fremde Aussagen markieren
Hay que dejar claro que hablo **del texto**, no de mi opinión. Dos formas:

1. **indirekte Rede (Konjunktiv I):**
   *Der Journalist berichtet, dass jedes Jahr eine große Anzahl von Menschen das Land **verlasse**.*
2. **Quellenangabe:**
   *Laut … (Verfasser/in / Quelle) …* — *(Verfasser/in / Quelle) zufolge …*

### Mini-chuleta de Konjunktiv I (3.ª persona)
| Infinitiv | er/sie/es | sie (Plural) → si coincide con el indicativo, usar Konjunktiv II |
|---|---|---|
| sein | sei | seien |
| haben | habe | hätten |
| werden | werde | würden |
| können | könne | könnten |
| müssen | müsse | müssten |
| geben | gebe | gäben / würden … geben |

## 💡 Consejos
- En la Textwiedergabe **no** doy mi opinión (nada de "ich finde", "leider").
- No copies frases enteras del texto: cambia palabras (Synonyme) y estructura.
- Tiempo verbal: presente.
