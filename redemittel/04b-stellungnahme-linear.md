# 4b. Begründete Stellungnahme – lineare Erörterung (una sola postura)

> **¿Qué tengo que hacer?** Defender **una sola postura** (a favor **o** en contra) con varios argumentos que se refuerzan, y **rebatir o relativizar** los argumentos contrarios.

## Was musst du tun?
- deine eigene Meinung zur vorgegebenen Fragestellung verdeutlichen
- deine eigene Meinung durch eine differenzierte Argumentation stützen
- dich (möglichst) auch kritisch mit Gegenargumenten auseinandersetzen, diese entkräften/widerlegen
- zum Schluss überleiten

## Aufbau – zwei Wege
**Weg 1 – Meinung als These:** eigene Meinung → Argument 1 → Argument 2 → Argument 3 …
**Weg 2 – Meinung als Conclusio:** Argument 1 → Argument 2 → Argument 3 … → eigene Meinung

⚠️ Denke auch an die **Widerlegung oder Relativierung von Gegenargumenten**. So muestras que esos argumentos solo valen de forma limitada o son falsos.

Cada argumento debe estar **ausgearbeitet**: These → Begründung → Beleg/Beispiel → Schlussfolgerung (ver `04a`).

## Redemittel

### die eigene Meinung vorab konkret benennen
- Meiner Ansicht nach kann die Frage, ob …, ganz klar mit „Ja“/„Nein“ beantwortet werden, was ich im Folgenden verdeutlichen werde.
- Ich bin der Meinung, dass … Dies werde ich im Folgenden genauer ausführen.

### Argumente / Vor- und Nachteile / Belege / Beispiele benennen
→ siehe Redemittel zur dialektischen Erörterung (`04a-stellungnahme-dialektisch.md`)

### Gegenargumente einführen
- Ein (wichtiges, beliebtes) Argument / Das Hauptargument für … ist Folgendes: …
- Gerne weisen die Gegner/Befürworter/innen von … darauf hin, dass …
- Dabei gehen die Gegner/Befürworter/innen von … von folgender Annahme / von folgender Voraussetzung / von folgenden Rahmenbedingungen aus: …

### Gegenargumente widerlegen oder relativieren
- Dies gilt aber nur / ist aber nur dann richtig, wenn man davon ausgehen kann, dass …
- Dabei wird gerne übersehen/vergessen, dass …
- Genau diese Annahme/Voraussetzung aber ist (nachweislich) falsch, denn …
- Diese Rahmenbedingungen existieren aber heute noch nicht.
- Die Gegner/Befürworter/innen von … berücksichtigen dabei nicht, dass …
- Die Argumente der Gegner/Befürworter/innen von … sind in sich widersprüchlich / widersprechen sich: So wird einerseits behauptet, dass …, andererseits wird darauf hingewiesen, dass …

### die eigene Meinung als Schlussfolgerung (Conclusio) formulieren
- Abschließend/Zusammenfassend lässt sich die Situation wie folgt bewerten: …
- Auch wenn vieles dafür/dagegen spricht, halte ich persönlich …
- Betrachtet man die genannten Argumente, muss man zu dem Schluss kommen, dass …
- Mein persönliches Fazit sieht wie folgt aus: …
- Um abschließend auf die Ausgangsfrage zurückzukommen: …
- Wie man meiner Argumentation entnehmen kann, bin ich für/gegen …

## 💡 ¿Dialéctica o lineal?
- **Dialéctica**: más segura si tienes dudas o el tema tiene dos lados claros. Es más fácil llegar a "differenzierte Argumentation".
- **Lineal**: buena si tu opinión es muy clara, pero **no olvides** al menos un Gegenargument con su Widerlegung; si no, la argumentación parece poco diferenciada.
